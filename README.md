# AFTHO Frontend

AFTHO is a business diagnostics website focused on tracing missed-revenue and opportunity leaks. The visual and UX authority for this project is [`design.md`](./design.md); repository operating rules live in [`AGENTS.md`](./AGENTS.md).

## Getting Started

Run the development server with pnpm:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000). The current page is a Phase 1 design-system test surface, not the final homepage.

## Checks

```bash
pnpm lint
pnpm build
```

Motion is intentionally deferred until Phase 2 requires animation.
